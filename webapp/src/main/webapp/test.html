Step 1 — Confirm Platform is Running

Open in browser http://localhost:8080/openmrs/
Expected "OpenMRS Platform 2.5.15 Running!" — database initialized, no UI module installed
Actuator health http://localhost:8081/actuator/health → {"status":"UP"}

Step 2 — Install webservices.rest Module (for REST API)

OpenMRS Core has no REST API built-in — it's provided by a module.

  1. Download: webservices.rest-omod-2.42.0.omod
  2. Copy to: %APPDATA%\OpenMRS\modules\ (currently empty)
  3. Restart: java -jar webapp\target\openmrs.war
  4. Test: http://localhost:8080/openmrs/ws/rest/v1/

After install, use admin / Admin123 as Basic Auth credentials for all REST calls.

Step 3 — REST API Endpoints (after module installed)

MethodURLDescription

Step 5 — Install Legacy UI (for login page)

To get a traditional OpenMRS login/admin UI:

  1. Download legacyui module
  2. Copy .omod to %APPDATA%\OpenMRS\modules\
  3. Restart the app
  4. Navigate to http://localhost:8080/openmrs/login.htm
